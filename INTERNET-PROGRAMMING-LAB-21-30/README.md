# Internet Programming Lab Experiments 21–30

Ten separate project folders, following the same folder structure as the previous 1–20 package.

Every project contains `css/`, `js/`, `pages/`, `README.md`, `index.html`, `package.json`, and `serve.js`.

Open a project's `index.html` in a browser or run `npm start` from that project folder. The interfaces include sample records, search and a basic admin panel for adding and deleting records. They are front-end lab prototypes; real back-end services and external integrations are not connected.

Note: The source document repeats the number 28 for the event-page question and then labels the journal website as 30. To keep the requested sequence unambiguous, the event page is named folder 29 and the journal website folder 30.
