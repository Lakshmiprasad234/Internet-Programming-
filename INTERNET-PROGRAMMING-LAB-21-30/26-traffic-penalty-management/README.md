# Traffic Squad Penalty Management System

Based on Experiment 26 in the uploaded Internet Programming Lab document.

## Structure
- `css/style.css` — responsive styling
- `js/config.js` — experiment-specific fields and sample records
- `js/app.js` — shared page rendering, search, add and delete functionality
- `pages/login.html` — simulated login form
- `pages/admin.html` — admin record management page
- `index.html` — main output page
- `package.json` and `serve.js` — optional local server

## Run
Open `index.html` in a browser, or run `npm start` in this folder (Node.js required) and visit `http://localhost:3000`.

## Note
This is a front-end lab demonstration. Browser localStorage is used for demo records. Real backend/database, authentication, payment, OTP, email/SMS, maps and external integrations are not connected.
